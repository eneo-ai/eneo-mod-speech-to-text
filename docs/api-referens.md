# API-referens

Anropen som webbläsaren kan göra mot modulen, och de anrop till Eneo som modulen släpper igenom. Uppräkningen kommer ur koden: [Backend](backend.md) förklarar reglerna bakom den.

Referensen byggs från [OpenAPI-beskrivningen](api/openapi.json) som backenden exporterar. På dokumentationssajten har varje anrop en egen sida med parametrar, begäran och svar.
