# Tal till text

En Eneo-modul: du spelar in ett samtal i webbläsaren eller laddar upp en ljudfil, och ett publicerat Eneo-flöde gör text av det.

Dokumentationen finns på https://eneo-ai.github.io/eneo-mod-speech-to-text/ och i [`docs/`](docs/).

- **Sätta upp modulen:** [Kom igång](docs/kom-igang.md), från Eneo till en driftsatt modul.
- **Egen logga och färg:** [Byt organisation](docs/branding.md).
- **Drift och felsökning:** [Drift](docs/operations.md).
- **Utveckla:** [Lokal utveckling](docs/development.md). Arbetar du som AI-agent, börja med [`AGENTS.md`](AGENTS.md) (engelska).
