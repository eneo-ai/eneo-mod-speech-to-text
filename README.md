# Tal till text

Tal till text är en Eneo-modul (repot heter `eneo-mod-speech-to-text`): du spelar in ett samtal i webbläsaren eller laddar upp en ljudfil, och ett publicerat Eneo-flöde gör text av det.

Dokumentationen finns på https://eneo-ai.github.io/eneo-mod-speech-to-text/. Källfilerna ligger i [`docs/`](docs/). Arbetar du som AI-agent, börja med [`AGENTS.md`](AGENTS.md) (engelska).
